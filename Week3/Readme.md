# DATA 607 – Assignment 3A: Global Baseline Estimate

This project implements a Global Baseline Estimate recommender system
using movie rating survey data.

## Files
- Week3A.qmd: Quarto file containing code and explanation
- MovieRatings.xlsx: Input movie ratings dataset

## Reproducibility
To reproduce results:
1. Clone this repository
2. Open Week3A.qmd in RStudio
3. Ensure required packages are installed
4. Render the file

The analysis is fully reproducible and produces the same results.
