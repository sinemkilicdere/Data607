Comparing the results

The original example used Emma with the bing lexicon, which gives positive and negative categories. In the extension, I used The Time Machine with the AFINN lexicon, which gives numeric sentiment scores. This means the two analyses are slightly different. The first one shows how many positive and negative words appear, and the second one shows an overall sentiment score based on weighted word values.

Comparison - Conclusion

I analyzed the sentiment of Emma using the bing lexicon. The results showed how many words were positive and how many were negative.

In the extended analysis, I used a different text, The Time Machine, and applied the AFINN lexicon. Instead of just positive or negative labels, AFINN provides numeric scores. This allowed me to calculate an overall sentiment score for the text.

The results are different in two main ways. First, the type of text changes the sentiment because different books use different language and tone. Second, the lexicon changes the outcome because bing uses categories, while AFINN uses numeric values. This means the interpretation of sentiment is more detailed in the second case.

Overall, this shows that sentiment analysis results depend both on the text corpus and the lexicon used.
